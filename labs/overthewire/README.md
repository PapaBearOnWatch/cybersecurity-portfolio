# OverTheWire — Bandit

## Overview

I used the OverTheWire Bandit wargame to develop practical Linux and command-line skills in a hands-on environment.

The exercises required me to examine files, identify clues, test different approaches, and use Linux tools to solve progressively more difficult challenges.

Rather than simply memorizing commands, I focused on understanding what the information in each challenge was telling me and using that information to determine my next step.

## Skills and Concepts Practiced

- Linux command-line navigation
- File and directory investigation
- Reading and manipulating files
- Searching for information with command-line tools
- File permissions
- SSH connections
- Working with compressed and archived files
- Identifying file types
- Encoding and decoding data
- Encryption concepts
- Git repositories and Git history
- Network service enumeration
- Basic scripting and command-line problem solving
- Troubleshooting when an expected approach did not work

## What I Learned

The Bandit challenges helped me become more comfortable working from the command line and investigating unfamiliar situations.

One of the biggest lessons was learning to look at the clues provided by a system before deciding what command or technique to try.

I also learned that troubleshooting is part of the process. When an approach failed, I had to examine what happened, reconsider my assumptions, and try another approach.

## Connection to Cybersecurity

Although Bandit is a learning environment, many of the skills involved are useful in cybersecurity work.

Investigating files, examining system information, understanding permissions, working with authentication, analyzing data, and using network tools are all skills that can contribute to defensive security and cybersecurity investigations.
