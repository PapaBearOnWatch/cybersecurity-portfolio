**Completed:** September 2026

This course provided an introduction to core cybersecurity concepts and the role of cybersecurity in protecting information, systems, networks, and users.

### Topics Studied

- Cybersecurity fundamentals
- Common cyber threats and attacks

- Authentication and access control
- Data protection

The course gave me a foundation for understanding how attacks occur and how defensive security practices can reduce risk.

It also reinforced my interest in pursuing hands-on cybersecurity work, particularly in defensive security and investigation.
